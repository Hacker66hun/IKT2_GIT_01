# 01 – GIT gyakorlat

A feladat célja egy egyszerű, reszponzív statikus weboldal elkészítése HTML és CSS segítségével,
külső third party könyvtárak használata nélkül. A projekt során a Git és GitHub alapvető
funkcióit, a branch-ek használatát és a Pull Request-ek kezelését gyakoroljuk.

A fejlesztés több külön ágon történik, majd ezek Pull Request segítségével kerülnek beolvasztásra
a main ágba.

## Felhasznált technológiák

- **GIT**
- **HTML**
- **CSS**
- **JavaScript**

---

### **GIT**
A GIT egy elosztott verziókezelő rendszer, amely lehetővé teszi a forráskód változásainak
követését, valamint a változások visszaállítását.

### **HTML**
A HTML egy leíró nyelv, amelyet a böngészők értelmeznek, és a benne található információk
alapján jelenítik meg a weboldal tartalmát.
Példa:
<!DOCTYPE html>
<html lang="hu">
<head>
  <meta charset="UTF-8">
  <title>Statikus oldal</title>
</head>
<body>
  <h1>Üdvözöllek az oldalon</h1>
</body>
</html>

|---------|-------|

### **CSS**
A CSS a weboldalak megjelenéséért felelős stílusleíró nyelv, amely a HTML elemek kinézetét
szabályozza.
Példa:
body {
  font-family: Arial, sans-serif;
  background-color: #f0f0f0;
}
